## 1. Paper

::: {.definition #def-sheet name="sheet" defines="term-face"}
A sheet is a simple polygon $P \subset \mathbb{R}^2$.
:::

::: {.term #term-face name="face"}
A convex polygon of the decomposition on which $f$ is a single isometry.
:::

Prose between the two definitions, citing Hull [@hull2020, chapter 6].

::: {.definition #def-flat-state name="flat folded state" defines="term-table"}
A flat folded state of a sheet $P$ is a pair $(f, \lambda)$.
:::

::: {.term #term-table name="table"}
The plane a state is folded onto, the image of $f$.
:::

::: {.term #term-hinge name="hinge" defined-by="def-flat-state"}
