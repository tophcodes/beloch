# 2026-06-28 (2) — v0.0 minimal core landed

The first vertical slice runs end to end: `beloch fold examples/diagonals.bel`
parses, evaluates (exact ℚ), planarizes, and emits valid FOLD.

## What shipped

- Exact rational geometry (`zarith`): axiom 1 (`through`), axiom 2 (`fold .x to
  .y`), line intersection, clip-to-square, segment intersection — no float, no
  epsilon ([ADR 0008](../decisions/0008-exact-rational-arithmetic.md)).
- sedlex lexer + menhir grammar → AST with source spans; `Beloch.parse`.
- Eval: name resolution (4 corners pre-bound), named/anonymous creases, derived
  `cross` points, precondition errors (identical points, parallel/off-paper
  `cross`, undefined names).
- Planarize: boundary + creases split at on-paper intersections, vertices
  deduped.
- FOLD emit: `"B"`/`"U"` assignments, `beloch:edges` provenance.
- CLI `beloch fold FILE`; Nix flake `packages.default` (build + `doCheck`) and
  `apps.default` (`nix run`).
- 22 tests (unit geom/state/eval/planarize/emit + e2e), all green.

Built via subagent-driven development: 9 TDD tasks, each implemented + reviewed
by fresh subagents. Two real gotchas recorded in
[antipatterns.md](../antipatterns.md): the dune facade re-export requirement and
the `fold_emit`↔`beloch` module cycle.
