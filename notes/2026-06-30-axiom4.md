# 2026-06-30 — Axiom 4 (project a point onto a line)

`map .p onto --l1 perp --l2`. Classic Justin operation ④, `(P → D, D' → D')`:
bring `p` onto `l1` with the crease perpendicular to `l2`. Three names for one
constraint — "crease ⊥ l2", "l2 maps to itself", "project parallel to l2".

## The numbering trap, again

Wikipedia and the OEIS-style references call this **O7**; Wikipedia's **O4** is
our already-shipped axiom 3 (perpendicular through a point). Beloch tracks
classic Justin numbering, so it is **axiom 4** here. The user found it as "O4"
on Wikipedia and we nearly built the wrong operation — same Caruana-Pace-class
trap noted in `antipatterns.md`. Grounded the final call in `refs/justin1986.md`
§8.1, which lists ④ explicitly with constraint `¬(P ∈ D ∧ D ∥ D')`.

## Construction (exact, no sqrt)

`m` = line through `p` parallel to `l2`; `Q = m ∩ l1`; crease =
perpendicular-bisector of `p`–`Q` (automatically ⊥ l2). Lives in `Geom`
(`project_crease`, returns `option`); eval turns `None` into the parallel-lines
error. Stays in ℚ — operations ①–④ never leave the rationals (§8.2a), so no
`Num` work, unlike axiom 5's square roots. The first cube root waits for axiom 6.

## Edge cases

- `l1 ∥ l2` → `None` → error (covers both 0-solution and ∞-solution sub-cases).
- `p ∈ l1`, `l1 ∦ l2` → `Q = p`, degenerate bisector → crease = perpendicular to
  `l2` through `p`. One valid solution.
