# Beloch v0.5 — crease names in FOLD + diagram labels — Design

> **Status:** design, pending approval. Implementation plan appended by
> writing-plans. Based on **`main`** (independent of axiom 5) so it can merge as
> its own PR *before* #3; PR #3 (axiom 5) then rebases onto the updated main.
> Demoed on the existing named-crease examples (`perp.bel` → `--diag`,
> `diagonals.bel` → `--d1`/`--d2`).

## Goal

Show each **named** crease's name (`--v`, `--diag`, …) on the rendered diagram.
The FOLD output currently carries, per crease edge, only its axiom + source
inputs — not the bound name — so `tools/fold2svg.mjs` can't label by name. This
slice adds the name to the FOLD output and labels it in the tool.

## Part 1 — beloch emits the crease name (output contract, additive)

- `State.provenance` gains `name : string option` (the crease's bound name, or
  `None` for an anonymous `fold .a to .b`).
- `Eval.eval` already has the `name_opt` from `Ast.Crease (name_opt, ax, span)`;
  thread it into the provenance record.
- `Fold_emit` adds a `"name"` key to each crease entry in `beloch:edges`: the
  string, or `null` for an anonymous crease. (Boundary edges stay `null` whole
  entries, as today — they have no provenance.)
- Spec §7: document the new `name` field on `beloch:edges`.
- Additive only — no existing field changes; stock FOLD consumers ignore it.

## Part 2 — tool labels the name (one boundary exit, outside)

- `tools/fold2svg.mjs` reads `prov[i].name`. For each **named** crease, place its
  name as a small label just **outside** the paper, near one boundary exit of the
  crease — i.e. a vertex of a crease edge that lies on the unit-square boundary
  (`x∈{0,1}` or `y∈{0,1}`), offset outward. Colour the label to match the crease's
  axiom colour.
- One label per crease name (not per sub-edge): dedupe by name, pick one boundary
  vertex. Anonymous creases: no name label (the axiom legend still applies).
- If a named crease has no boundary vertex (fully interior — not possible for the
  current single-square paper, every clipped crease meets the boundary), fall back
  to its midpoint. (Documented; not expected to trigger.)

## Version

The `name` field is **additive and backward-compatible** (stock FOLD consumers
ignore it), and the parallel axiom-5 PR (#3) is already bumping the creator to
`0.3.0-dev`. To avoid a version collision across the two in-flight PRs, this slice
**does not bump the version** — it keeps whatever `main` has. (When #3 rebases on
top, it carries its own bump.)

## Testing

- **eval/provenance:** a named crease (e.g. `--diag`) carries its `name`; an
  anonymous crease (`fold .a to .b` with no `--name`) carries `None`.
- **emit:** `beloch:edges` includes `"name"` (string for a named crease, `null`
  for an anonymous one; boundary edges stay whole-`null` entries).
- **tool:** rendered SVG of `perp.bel` contains the text `--diag` (the named
  crease); `diagonals.bel` shows `--d1` and `--d2`. Assert via a string check on
  the SVG output.
- **regression:** existing tests stay green (the provenance struct gains a field;
  only `eval`'s construction and any direct constructors change).

## Out of scope

Labelling derived points (`.center`) — the FOLD has no point names either; that
would be a separate emit change. Overlap-avoidance for labels (YAGNI for the
small examples). Mountain/valley, other axioms.

- [ ] **Step 1: Write the failing tests**

Add to `tests/test_beloch.ml`:

```ocaml
let test_eval_crease_name () =
  let cs = eval_src "paper square\n--d1: through .a .c\nthrough .b .d\n" in
  let named = List.nth cs 0 and anon = List.nth cs 1 in
  Alcotest.(check (option string)) "named crease carries its name"
    (Some "d1") named.Eval.prov.State.name;
  Alcotest.(check (option string)) "anonymous crease has no name"
    None anon.Eval.prov.State.name

let test_emit_crease_name () =
  let cs = eval_src "paper square\n--d1: through .a .c\n" in
  let st = Planarize.run cs in
  let json = Fold_emit.to_json st (Faces.extract st) in
  let open Yojson.Safe.Util in
  let names =
    json |> member "beloch:edges" |> to_list
    |> List.filter_map (function `Null -> None | e -> Some (e |> member "name"))
  in
  Alcotest.(check bool) "a crease entry carries name \"d1\"" true
    (List.exists (fun n -> n = `String "d1") names)
```

Register `test_eval_crease_name` in the `eval` group and `test_emit_crease_name`
in the `emit` group of `Alcotest.run`:

```ocaml

```

## Task 2: tool labels the crease name

**Files:** Modify `tools/fold2svg.mjs`.

**Interfaces:**
- Consumes: the `name` key on `beloch:edges` (Task 1).
- Produces: named creases get a small `--name` label at one boundary exit,
  coloured by axiom; anonymous creases get none.

- [ ] **Step 1: Add the labelling pass**

In `tools/fold2svg.mjs`, after the vertex/corner-label loop and before the
`// title` line, insert (uses the existing `V`, `E`, `prov`, `tx`, `ty`,
`eColor`, `minX/maxX/minY/maxY`):

```javascript
// crease-name labels: one per NAMED crease, at a boundary exit, just outside
const onB = (p) => {
  const e = 1e-6;
  return Math.abs(p[0] - minX) < e || Math.abs(p[0] - maxX) < e ||
         Math.abs(p[1] - minY) < e || Math.abs(p[1] - maxY) < e;
};
const creases = {};
E.forEach((e, i) => {
  const nm = prov[i] && prov[i].name;
  if (!nm) return;
  if (!creases[nm]) creases[nm] = { vs: new Set(), col: eColor(i) };
  creases[nm].vs.add(e[0]);
  creases[nm].vs.add(e[1]);
});
for (const [nm, { vs, col }] of Object.entries(creases)) {
  const list = [...vs];
  const bi = list.find((j) => onB(V[j]));
  const p = V[bi !== undefined ? bi : list[0]];
  const e = 1e-6;
  let dx = 0, dy = 0, anchor = "middle";
  if (Math.abs(p[1] - minY) < e) dy = 18;        // bottom edge -> below
  else if (Math.abs(p[1] - maxY) < e) dy = -10;  // top edge -> above
  if (Math.abs(p[0] - minX) < e) { dx = -8; anchor = "end"; }   // left edge
  else if (Math.abs(p[0] - maxX) < e) { dx = 8; anchor = "start"; } // right edge
  out.push(`<text x="${tx(p[0]) + dx}" y="${ty(p[1]) + dy}" font-size="13" font-weight="600" fill="${col}" text-anchor="${anchor}">--${nm}</text>`);
}
```
