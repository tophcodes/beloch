Beloch ist eine deklarative Sprache für Origami, gebaut auf den
Huzita–Justin-Axiomen. Programme beschreiben Punkte, Linien und Faltungen;
Beloch wertet sie zu einem Faltbild (crease pattern) und einem gefalteten
Zustand aus.

```beloch
paper square
mark map .a onto .c
```
