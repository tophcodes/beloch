Ein `.bel`-Programm beschreibt ein Blatt Papier und wirkt schrittweise darauf ein. Dieser Abschnitt legt die drei Grundbegriffe, aus denen alles andere folgt: das Papier, die Werte darauf, und die zwei Arten, es zu verändern.

## Das Papier

Ein Programm beginnt mit der Deklaration seines Blatts:

```beloch
paper square
```

`paper square` ist das Einheitsquadrat mit vier fest gebundenen Eckpunkten, gegen den Uhrzeigersinn ab dem Ursprung benannt:

| Name | Koordinaten |
| --- | --- |
| `.a` | `(0, 0)` |
| `.b` | `(1, 0)` |
| `.c` | `(1, 1)` |
| `.d` | `(0, 1)` |

Andere Papierformen unterstützt die Sprache derzeit nicht (`spec/SPECIFICATION.md §2`).

## Werte: Punkte und Kanten

Zwei Wertarten, unterschieden am Sigil (`spec/SPECIFICATION.md §3`):

- **Punkt** — `.name`. Die vier Ecken, plus jeder Punkt, der durch eine Konstruktion abgeleitet wird (z. B. ein Schnittpunkt `--x * --y`).
- **Kante / Linie** — `--name`. Der geometrische Wert einer Faltung: eine (unendliche) Linie. In der Ausgabe erscheint sie als Kante der Flächen des gefalteten Zustands; `mark`/`fold` wirken mit ihr auf das Papier ein.

Alle Geometrie ist exakt — keine Gleitkommazahlen, keine Toleranzen (`spec/SPECIFICATION.md §6`).

## Eine Bewegung ist ein reiner Lesevorgang

`map .a onto .b`, `through .a .b`, `perp --l through .p` — diese **Bewegungen** (motions) berechnen eine Linie, ohne das Papier zu berühren. `--l = map .a onto .b` bindet einen Wert; für sich genommen bewirkt die Zeile nichts auf dem Blatt (`spec/SPECIFICATION.md §4.10`). Das gilt seit v0.21-dev auch für `through`: "die Linie durch zwei Punkte" ist so träge wie jede andere Bewegung, bis ein Dispositions-Verb darauf einwirkt.

Das Gesetz dahinter: **eine Operation, die den Papierzustand verändert — eine Kante ritzt, faltet, und dadurch bestehende Referenzen neu segmentiert — ist ein Schlüsselwort-Verb, sequenziert in Programmreihenfolge; eine Operation, die nur den aktuellen Zustand liest, oder nur eine geometrische Linie beschreibt, ohne das Papier zu berühren, ist ein reiner Lesevorgang** (`spec/SPECIFICATION.md §4.10`).

## Zwei Dispositionen: `mark` und `fold`

Um wirklich auf das Papier einzuwirken, braucht eine Bewegung eines von zwei Dispositions-Schlüsselwörtern (`spec/SPECIFICATION.md §4.6`):

- **`mark`** — ritzt die Linie und lässt das Blatt **flach**: unterteilt die Lagen, die sie kreuzt, in Flaps, bewegt aber nichts. Emittiert FOLD `F` — vorhanden, nicht gefaltet — mit einer M/V-*Absicht* im Faltbild-Frame.
- **`fold`** — ritzt die Linie **und faltet sie**: unterteilt und bewegt Lagen. Emittiert FOLD `M`/`V` in beiden Frames.

```beloch
mark map .a onto .b                    ; ritzt, bleibt flach (Tal-Absicht)
mark --d = through .a .c               ; benannte Kante, bleibt flach
fold map .a onto .c moving .a          ; faltet den Flap mit .a, Tal
fold map .a onto .c moving .a mountain ; ... als Berg
```

`@` gibt es nicht mehr: Es gibt keinen vom Verb selbst getrennten Faltmarker — `mark`/`fold`/`collapse` tragen die Schreiboperation direkt in sich.
