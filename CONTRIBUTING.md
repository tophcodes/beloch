# Contributing to Beloch

Beloch is a proof of concept. For now, my main focus is cleaning up the whole
project step by step: the specification, the documentation, the code layout and
the interfaces. While that cleanup runs, I take contributions as issues and
feedback, and I do not merge pull requests from outside.

Open an issue on [GitHub](https://github.com/tophcodes/beloch/issues) when you:

- find a program that Beloch folds wrong, or one it rejects that it should fold;
- find a place where the documentation, the guide or the specification
  contradicts itself or the implementation.

A report of a wrong fold is most useful with the program that shows it, the
result you expected and the one Beloch gave.

Questions about the language, ideas and feedback on its design go to
[GitHub Discussions](https://github.com/tophcodes/beloch/discussions).
